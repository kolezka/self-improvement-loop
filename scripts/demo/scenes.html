A Claude Code plugin

self-improvement-loop

Claude Code that learns from your sessions.
Mistakes you keep repeating become skills, rules and hooks you keep.

How the loop worksruns in the background, outside your session

1 · hooks
Session
Hooks record events. They never block and never call a model.
2 · worker
Reflect
After the session, one model call turns the transcript into a lesson.
3 · cluster
Spot the pattern
The same lesson three times becomes a pattern.
×3
4 · curriculum
Draft
A skill, rule, hook or agent is staged on a git branch.
5 · you
Review
You accept or reject it in the web console or the CLI.
6 · delivery
Next session
The next matching session gets the lesson as context.
Then it keeps score
Usage and votes show whether each lesson actually helps.
used 7×3 good votesrefine or retire

Why use it

  • ✓Repeated mistakes turn into reusable skills
  • ✓Usage and votes show which ones actually help
  • ✓Local-first · hooks never block or call a model
  • ✓Nothing ships without your review
